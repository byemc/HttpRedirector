# HTTP Redirector

HTTP Redirector is just a simple program I wrote that gives you an option to pick what browser to open when you open a link in another program. (For instance, opening a link in a Word document but needing to open it in a different browser)

It's probably really specific to me but oh well

Downloads and installation instructions on [the releases page](https://github.com/byemc/HttpRedirector/releases/)
